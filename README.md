# tunk.ai x Pasco Group — Sales Pitch Deck

A self-contained interactive pitch deck with dynamic ROI calculator.

## Deploy on Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → New Project → Import your GitHub repo
3. Vercel auto-detects static — hit **Deploy**

No build step, no dependencies, no config needed beyond `vercel.json`.

## Local preview

Open `index.html` directly in any browser.
